# simPl 0.1.6

Read files where they are, keep one window, and choose where your library lives.

## New since 0.1.5

- **Open files where they are.** **Open file** (Ctrl+O), drag-and-drop,
  double-clicking a file in Explorer and **Open with** read the original file.
  Nothing is copied, and the book appears in **Recent**. **Add Document**
  (now Ctrl+I) still copies a book into your library. A Recent row has **Add to
  library**, which copies it and keeps your reading position. TXT and Markdown
  files open in place too. This answers
  [#1](https://github.com/Tikkaaa3/simPl-reader/issues/1).
- **One window.** Opening a file from Explorer while simPl is running opens it in
  that window and brings the window to the front, even when it is minimized.
  Starting simPl again without a file brings the window forward. A file that
  arrives during a dialog, a save or a backup opens as soon as the reader is
  free. If the running window runs as administrator or doesn't respond, the new
  launch says so instead of opening a second window.
- **Choose where your library lives.** **Settings → Library & data → Library
  folder** shows where imported books are kept. **Change…** moves them to a
  `simPl Library` folder inside a folder you pick, for example on another drive.
  simPl copies and checks every book before it switches, so **Cancel**, a full
  disk, an unplugged drive or a crash leaves your library where it was. A move
  that a crash interrupts after the switch finishes the next time simPl starts.
  **Use default folder** moves the books back. If the folder goes missing,
  **Find it…** accepts it under a new drive letter, and **Stop using this
  folder…** returns to the default folder without deleting anything.
- **A reading bar that stays out of the way.** In a document, the title bar and
  the reading toolbar are one floating bar. It hides when you aren't using it and
  shows when you move the pointer to the top of the window or press Tab. The page
  never moves, and it gets the whole window height. F8 pins the bar.

## Improved

- Clicking a library card after **Locate** no longer copies the file again, and
  the card opens even after you edit the original.
- The installer adds simPl to **Open with** for `.htm`, `.xhtml` and `.markdown`
  files, as well as PDF, EPUB, HTML, TXT and Markdown.
- A restore that a crash or power loss interrupts is finished or undone the next
  time simPl starts.
- The title bar always uses standard Windows minimize, maximize and close
  buttons. The macOS-style option is gone.

## Changed shortcuts

- **Ctrl+O** opens a file in place. **Ctrl+I** adds a document to your library.
- **F8** pins and unpins the floating reading bar.

## Upgrading from 0.1.5

Install over the existing version. Your library, preferences, reading positions,
notes and downloaded dictionaries are kept.

- Books already in your library stay as simPl's copies. Nothing is migrated.
- To read a book from its original file instead, open that file with **Open
  file**. Notes, highlights and per-book typography carry over, because they
  follow the book's content. The reading position starts again, because it
  follows the file's location.
- To open supported files with a double-click, choose **simPl Reader** in **Open
  with** and select **Always**. Windows doesn't let an app make itself the
  default.
- The library folder setting is not part of a backup. Restoring a backup keeps
  your current library folder.
- Uninstalling simPl keeps a library folder outside `%LOCALAPPDATA%\simPl`.

## Downloads

- **`simPl-0.1.6-windows-x64-setup.exe`**: per-user Windows installer with
  PDFium and notices included.
- **`simPl-0.1.6-windows-x64-portable.zip`**: extract the whole folder and run
  `simPl.exe`. Keep `pdfium.dll` and `third-party` beside it. Portable and
  installed copies share the same Windows-profile library, so only one of them
  runs at a time.
- **`SHA256SUMS`** and **`release.json`**: checksums and installer metadata.

Windows x64 is the current target. The installer is unsigned. Dictionary packs
remain optional downloads. Reading and installed dictionary lookups work
offline. PDF Book view needs a usable text layer and does not perform OCR.
