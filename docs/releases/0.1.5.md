# simPl 0.1.5

More ways to read, listen and keep your reading data on your own machine.

## New since 0.1.4

- **Listen with Windows voices.** Start from the toolbar to read continuously
  across pages and EPUB chapters. The viewport follows the spoken line and a
  temporary word marker shows your place. Pause, resume and change the speed;
  select Listen again to stop. The selection menu can read just a passage.
  Voice and speed preferences are saved; speech works offline.
- **Offline word translation.** Double-click a word or use selection →
  right-click → Translate. Choose input/output languages and automatic lookup
  in Settings. Download or import only the dictionaries you need; lookups run
  locally after installation, with no document text sent online.
  There are 13 optional directions: English ↔ Turkish, Spanish, German, French,
  Japanese and Chinese, plus Korean → English. This is dictionary lookup;
  sentence translation and Argos plugins remain future work.
- **Library backup and note export.** Create and restore verified ZIP backups
  from Settings → Library & data. Include imported book files and downloaded
  dictionaries optionally. Export bookmarks, highlighted quotes and notes as
  Markdown, text or JSON. Restore shows a review and retains the previous
  profile in a recovery folder.
- **Reading comfort.** Toggle Book fit-width with the zoom percentage or
  Ctrl+Shift+F. Use F11 for fullscreen. Pick font, size, line spacing and side
  margins independently; reflowable books remember their own settings.
- **Custom shelves.** Organize, filter and sort your local collection, alongside
  favourites and Continue Reading.

## Improved

- Smoother Settings scrolling, including corrected icon clipping and reduced
  redundant painting at high DPI.
- Refined library, reading chrome and window controls, with clearer keyboard
  focus and better layouts at narrow window sizes.
- TXT and Markdown imports keep their original format labels in the library;
  Add Document text aligns correctly.
- Library save recovery and backup restore reject stale replies from a previous
  profile, protecting the reopened book's notes, typography and dictionary state.
- Updated documentation and a full-resolution promotional gallery showing the
  current interface, themes, Listen, dictionaries, notes and PDF views.

## Downloads and upgrading

- **`simPl-0.1.5-windows-x64-setup.exe`**: per-user Windows installer with PDFium
  and notices included. Install over the existing version to keep your library,
  preferences, positions, notes and downloaded dictionaries.
- **`simPl-0.1.5-windows-x64-portable.zip`**: extract the whole folder and run
  `simPl.exe`; keep `pdfium.dll` and `third-party` beside it. Portable and installed
  copies share the same Windows-profile library.
- **`simPl-0.1.5-promotional-media.zip`**: 22 full-window interface renders,
  2560 × 1600 PNGs and lossless WebP copies, captions and attribution. Demo books
  are not bundled with the application. These are production-widget renders,
  not OS desktop captures.
- **`SHA256SUMS`** and **`release.json`**: checksums and installer metadata.

Windows x64 is the current target. The installer is unsigned. Dictionary packs
remain optional downloads; reading and installed dictionary lookups work offline.
PDF Book view needs a usable text layer and does not perform OCR.
